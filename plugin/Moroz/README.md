# Мороз

Отдельный плагин для зимнего сервера CS2. Считает убийства спецназа и террористов и держит одну компактную плашку сверху экрана: `CT  04    02  T`.

Текст ледяной, со своей подложкой, и виден только тому игроку, над чьим взглядом он висит. Чужие плашки не передаются.

## Команды

Игроки пишут в чат `!moroz` и `!morozreset` — CounterStrikeSharp сам вызывает `css_moroz` и `css_morozreset`.

| Команда | Кто | Что делает |
| --- | --- | --- |
| `!moroz` | любой | спрятать или вернуть плашку |
| `!morozreset` | админ `@css/generic` или консоль сервера | обнулить оба счёта |

Свои убийства союзников не считаются. Это меняется в конфиге: `"CountTeamKills": true`. По умолчанию счёт живёт всю карту. `"ResetEachRound": true` обнуляет его в начале раунда.

## Установка

На сервере уже должны стоять Metamod и CounterStrikeSharp. На компьютере, где собираете плагин, нужен .NET 8 SDK.

```bash
dotnet build -c Release
```

Из `bin/Release/net8.0` скопируйте в `game/csgo/addons/counterstrikesharp/plugins/Moroz/` только три файла:

- `Moroz.dll`
- `Moroz.deps.json`
- `Moroz.pdb`

`CounterStrikeSharp.API.dll` рядом класть не нужно — он уже есть у самого CounterStrikeSharp, а копия в папке плагина ломает загрузку.

Перезапустите карту. Конфиг появится сам:

`game/csgo/addons/counterstrikesharp/configs/plugins/Moroz/Moroz.json`

Готовый пример лежит в `example-config/Moroz.json`. Его можно положить по пути выше до первого запуска.

## Если плашка не там

Меняйте только конфиг, пересобирать не нужно. После правки: `css_plugins reload Moroz`.

| Поле | Смысл |
| --- | --- |
| `Up` | выше или ниже. Больше — ближе к верхнему краю |
| `Forward` | дальше от камеры. Если режет прицел, увеличьте |
| `Right` | сдвиг вбок. 0 — по центру |
| `FontSize` | размер букв |
| `UnitsPerPixel` | масштаб. Меньше — крупнее надпись |
| `FontName` | шрифт, который есть на сервере. Обычно `Arial` |
| `Red` `Green` `Blue` | цвет льда, 0–255 |
| `Background` | тёмная подложка под текст |

Зимний вид по умолчанию: светлый лёд `214 232 242`, тёмная плашка, полный яркий шрифт, чтобы на снежной карте цифры не терялись.
